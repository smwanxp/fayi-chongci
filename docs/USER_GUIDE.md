# 法忆冲刺使用说明

这是一份面向实际使用者的说明。法忆冲刺运行在飞书应用中，管理员负责维护共享内容，学习用户负责自己的复习。题库内容可以同步，个人掌握度、错题、笔记和复习进度不会因别人学习而改变。

## 1. 登录与角色

从飞书工作台打开“法忆冲刺”。只有被管理员加入并授予角色的账号可以使用：

- 管理员：维护题库、每日一题、知识关联和用户；可以给学生添加备注、选择内容同步范围。
- 学习用户：学习自己的题库，记录自己的答案、熟悉度、笔记和复习进度。

如果页面提示没有权限、数据为空或无法加载，先确认当前登录的是正确的飞书账号，再联系管理员。不要反复刷新或清空数据。

## 2. 首页：今日冲刺

首页会根据复习状态安排今日任务，通常优先：

1. 已逾期内容；
2. 最近答错的内容；
3. 标记为忘记、模糊、不熟悉的内容；
4. 正常到期内容；
5. 当日允许加入的新卡。

首页显示完成量、今日目标、薄弱提醒和考试倒计时。今日队列不是全部题库，目的是控制当天压力；想自由选择内容时进入“速记模式”“带背模式”或“模拟组卷”。

## 3. 口诀完整默写

在“速记模式”和“模拟组卷”的二级入口中选择“口诀完整默写”，再选择科目、章节、数量和顺序：

- 按顺序：可选择一个章节、多个章节或整个科目。
- 随机：从符合筛选条件的卡片中打乱抽取。
- 数量：选择 5、10、15、20 等；某章节少于 5 张时，仍可按实际数量开始，不会被拦截。
- 中途退出：当前试卷会保存，下次可以继续。
- 已完成并标记为掌握的卡片，在同一复习轮次不会重复；标记模糊、不熟悉或忘记的卡片会继续进入滚动复习。
- 需要重新开始时，在组卷入口使用“重置本轮”。

答题时先看标题/提示，在输入区完整复述口诀或知识点，再按“显示答案”核对。提交后选择“忘记、模糊、记住、熟练”等掌握度。数字用阿拉伯数字或汉字数字均可，系统不应仅因数字写法不同判为错误；最终掌握度仍以自评和复习记录为准。

## 4. 正确/错误判断题自测

在判断题入口选择“判断题自测”，不要进入口诀默写页面。可选择科目、章节、数量以及按顺序/随机。

每题流程固定为：

1. 先点击“正确”或“错误”；
2. 提交后才显示标准结论、解析、法条依据和常见陷阱；
3. 选择自己的掌握度并进入下一题。

判断题的客观结果和主观掌握度会同时写入复习进度。即使答对但标记“模糊”，仍会按薄弱内容安排复习；答错的题会进入错题相关队列。

## 5. 速记模式

速记适合快速筛查漏洞，不要求输入长答案：

1. 选择科目、章节、顺序/随机、数量；
2. 选择是否把判断卡混入本轮；
3. 只显示标题或知识点，先在脑中回忆；
4. 选择“熟悉、不熟悉、模糊”；
5. 选择后自动显示口诀/答案/解析，再快速标记“记对了、记错了、模糊”。

已经在本轮速记中标记为掌握的内容不会再次加入本轮；不熟悉、模糊、记错的内容会进入滚动复习，并影响今日队列和下一次间隔。章节少于五条时也可以按实际条数开始。需要从头复习时点击“重置本轮”，重置只影响该轮的去重状态，不删除历史作答记录。

## 6. 带背模式

带背模式类似背单词，用于第一次过一遍或快速回顾：

1. 选择数量、科目/章节和按顺序或随机；
2. 页面依次展示口诀、标题、知识点和详细解释（资料有解释时才显示）；
3. 用“上一个”“下一个”翻看，可随时回看；
4. 完成后选择进入速记模式或口诀默写，立即把刚才的内容转入更深一层练习。

带背本身以理解和建立联系为主，最终掌握度应在速记或默写中确认。

## 7. 模拟组卷与中途继续

“模拟组卷”用于按考试形式集中完成一组题：

- 先选题型、数量、科目/章节和按顺序/随机；
- 可选择显示答案或先完成后统一核对；
- 交卷后查看完成量、正确率、各掌握度和错题；
- 中途退出会保存试卷和当前题号，下次进入可继续；
- “重置本轮”只重新安排本轮，不会抹掉历史日志。

自由复习也从入口开始选择范围，不会默认把所有科目一次性塞进同一场练习。

## 8. 每日一题

进入“每日一题”后可以看总览、开始练习、组卷和错题本：

- 组卷可按科目、掌握状态、数量和随机方式筛选；
- 有标准答案的题按答案判分；
- 资料没有可靠文字答案的题使用自评模式，不会强行制造答案；
- 错题可再次练习，达到设置的正确次数后才会从错题重点列表移除；
- 每日一题的记录与口诀复习记录分开统计，但都属于当前用户。
- 开源版只附带虚构示例题；部署者可以通过管理员界面添加自己拥有使用权的题目和解析。

## 9. 科目题库、知识体系和知识关联

- “知识体系”从学科到专题/章节再到考点展开，适合宏观浏览。
- “科目题库”可按科目、章节、标签和熟悉度筛选；点击卡片先看详情，不会直接强制进入默写。
- 卡片详情可查看口诀、知识点、解释、来源、关联和判断题；可从易混、例外、反例、法条、陷阱关系跳转。
- “知识关联”适合沿着关联链复习；移动端使用侧边栏展开，避免整页堆叠。
- 已归档内容不进入新组卷，但历史记录仍保留。

## 10. 复习统计与数据看板

“数据看板”比普通复习统计更详细，通常可以查看：

- 今日完成量、正确率、到期数、连续学习；
- 按科目查看总知识点、已掌握、未学习、薄弱和错题；
- 学习趋势、掌握程度分布、未来七天复习压力；
- 科目/章节层级明细，可从宏观科目逐层展开到具体知识点；
- 针对未掌握或薄弱内容直接开始专项训练。

图表中的掌握度来自当前用户的复习状态，不是单纯按背诵或每日一题数量推算。若刚恢复备份或刚同步内容，先刷新一次并等待本地数据完成加载。

## 11. 复习笔记

“复习笔记”是一套独立于背诵卡的知识笔记，主要用于统一复盘纸质真题、模拟题和教辅资料。整理原则是“题目是来源，知识点是主体”：

1. 一条笔记只记录一个独立知识点，并归入八科之一；章节、现有考点和自定义章节均可选择。
2. 正文支持标题、列表、粗体、链接、引用等文字格式；不支持图片和附件，方便长期检索和纯文字导出。
3. 可按需填写核心结论、规则解释、例外、易混知识、法条、个人错因、自编口诀和补充提醒。
4. 可以关联多个个人知识点、知识卡、相关科目和其他笔记。同一位置出现同名知识点时，可选择追加到原笔记或仍然新建。
5. 先在“资料库”建立真题、模拟题、教辅、教材或老师补充；以后给笔记附题时直接选择资料，再填写套卷、年份、题号、题型、题干、选项、答案和解析。除资料与题号外均可留空。
6. 页面会自动保存；顶部可按科目、章节、重要程度、状态、来源和关键词筛选。

提醒不会混入背诵卡任务。设置回看日期后，到期笔记会在首页出现单独的“笔记回看”入口。回看时可选择“仍需看（明天）”“已理解（7天后）”或“已掌握（停止提醒）”。

删除会先进入回收站，30天内可以恢复；永久删除需要再次确认。导出会按当前筛选生成一个纯文字 Markdown 文件，层级为科目 → 章节 → 知识点，并保留文字版来源题目。笔记、资料库、个人知识点和回看记录都只属于当前账号，不会被管理员同步给其他用户。

## 12. 资料导入

支持 JSON、CSV、Markdown、TXT、PDF、DOCX 等资料：

1. 上传文件并等待本机解析；
2. 检查标题、章节、口诀、知识点、解释和来源；
3. 处理重复项和无法识别的内容；
4. 编辑并确认草稿；
5. 批量入库后再到科目题库检查。

导入失败或关闭页面时，草稿不应自动变成正式题卡。法律表述、数字和例外规则必须人工核对，不要让系统擅自改写。

## 13. 设置、备份与恢复

“设置备份”可调整：

- 复习算法：固定曲线或自适应；
- 固定复习节点；
- 每日目标和新卡上限；
- 考试日期；
- 每日一题错题移除阈值；
- 速记是否混入判断卡。
- 全局字体大小：小、标准、大、特大；选择后立即生效并保存到当前账号。

备份流程：

1. 点击导出，保存完整 JSON 到安全位置；
2. 恢复前先导出当前版本，以便回退；
3. 选择备份文件并等待校验完成；
4. 恢复后检查科目、卡片、复习状态、笔记和设置。

“清空学习记录”只在明确想重新开始时使用。它会清理当前账号的掌握度、作答日志、每日一题状态和进行中的试卷，但不应删除题库、口诀、知识关联和笔记（页面会明确提示实际范围）。清空前一定要备份。

应用会先把每次操作即时保存到本机，再合并同步到飞书云端。公共题库、个人进度与笔记数据包放在文件存储；数据库只保存相对于公共题库的新增/修改内容和文件指针。首次升级到这一存储格式时会自动迁移，不需要重新导入题库。

## 14. 管理员：用户、备注与同步

管理员进入“用户管理”后可以：

- 从飞书组织通讯录添加允许学习的用户；
- 为用户添加或修改私有备注，例如姓名、班级或来源；
- 删除用户访问权限；
- 预览并选择要同步的内容范围。

同步建议按范围进行：先选择科目/章节，再选择口诀卡、判断卡、每日一题、知识关联等内容。同步完成后，学生下次打开或刷新即可获取内容副本。同步不会覆盖学生的掌握度、错题、笔记、复习设置和正在进行的试卷。

不要把学生备注写入共享题库，也不要用同步功能代替备份。

## 15. 推荐的一天

可以按以下顺序安排第三轮冲刺：

1. 首页完成逾期和薄弱任务；
2. 带背一个小章节，先建立全貌；
3. 速记筛查熟悉、不熟悉、模糊；
4. 对不熟悉内容做口诀完整默写；
5. 做同章节判断题，检查“一律/必须/可以”等陷阱；
6. 用数据看板查看科目薄弱点；
7. 在复习笔记补一两条真正容易忘的提醒。

不必一次把全部科目全部做完。短组、按章节和滚动复习更适合保持连续性。

## 16. 常见问题

**为什么已经做过的题又出现？**  
同一轮中已掌握内容会被去重；模糊、不熟悉、忘记和记错的内容仍会进入滚动复习。跨轮次或到期后再次出现是正常的。

**为什么一个章节不到五条也能开始？**  
现在按实际数量组卷，小章节不会因为少于五条被禁止。

**为什么判断题先不显示答案？**  
这是为了保留客观作答记录；必须先选正确/错误，提交后才显示解析。

**数字写法不同会被判错吗？**  
阿拉伯数字和汉字数字视为同一表达，不应单独因此判错；仍需保证实质内容完整。

**同步后我的复习记录没变吗？**  
正常。同步的是管理员选择的共享内容，个人掌握度、作答记录和笔记必须独立。

**页面打不开或数据不见了怎么办？**  
先确认飞书账号和网络，再刷新一次；不要清空数据。若仍异常，联系管理员并提供发生时间、页面和操作，不要发送密码或完整备份。
